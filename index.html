Riemann viewpoint

RN = Δx ∑i=0N−1 f(a + (i + ½)Δx),   Δx=(b−a)/N.

The domain is split into small intervals. One representative value is taken from each interval and multiplied by its width.

Lebesgue-style viewpoint

LB ≈ ∑j=0B−1 (yj+Δy/2) · μ̂({x : f(x) ∈ [yj,yj+Δy)}).

The range is split into value bins. The preimage of each bin is approximated by counting the domain samples whose function values fall into that bin.

Important limitation. This histogram is not an exact algorithm for arbitrary preimage measures: it estimates them from the same finite domain grid. The Dirichlet function is the counterexample. Every finite JavaScript Number is an exact rational number in binary floating-point representation, so a grid-only evaluator sees rational sample points and returns 1. The true Lebesgue integral is nevertheless 0 because the rationals have measure zero. The exact preimage-measure calculation is a mathematical result, not something a finite sampler can discover.

Exercise 2 — Numerical computation of the normal CDF

For a standard normal random variable, the CDF is the accumulated area under the Gaussian density. The page compares a fixed-cost error-function approximation, composite Simpson integration, and the power series derived by term-by-term integration.

Definition and special-function identity

Φ(z) = (1/√(2π)) ∫−∞z e−t²/2 dt
Φ(z) = ½ [1 + erf(z/√2)] = ½ erfc(−z/√2)

The identity is exact. The numerical implementation below approximates erf/erfc rather than replacing the special function with an elementary antiderivative.

Method 1 — Composite Simpson rule

Φ(z) = ½ + sgn(z) ∫0|z| φ(t) dt,   φ(t)=e−t²/2/√(2π).

With an even number n of subintervals, Simpson's rule has global error O(h⁴) for a sufficiently smooth integrand. It is accurate but each evaluation requires O(n) density evaluations.

Method 2 — Integrated power series

Φ(z) = ½ + (1/√(2π)) ∑k=0∞ (−1)k z2k+1 / [2k(2k+1)k!].

The implementation uses a recurrence between consecutive terms and stops when the terms are small after the sequence has started decreasing. It is excellent for moderate |z|, but cancellation makes a direct series less attractive in the far tails.

Method 3 — Abramowitz–Stegun 7.1.26 error-function approximation

erfc(x) ≈ e−x² · t(a₁ + t(a₂ + t(a₃ + t(a₄ + t a₅)))),   t=(1+px)−1,   x≥0.

The constants are p = 0.3275911, a₁ = 0.254829592, a₂ = −0.284496736, a₃ = 1.421413741, a₄ = −1.453152027, and a₅ = 1.061405429. Abramowitz and Stegun give an absolute error below 1.5 × 10⁻⁷ for the corresponding erf approximation; because Φ uses one half of erfc, the CDF error is at most about 7.5 × 10⁻⁸. For negative z the implementation evaluates the small positive tail directly, avoiding avoidable cancellation.

Why no elementary antiderivative? Liouville's theorem on elementary integration implies that an elementary primitive of e−x²/2 would require a rational function R satisfying R′ − xR = 1. A rational solution cannot have a pole (the derivative would create a higher-order pole), so R would have to be a polynomial; but then −xR has degree one higher than R and cannot combine with R′ to give the constant 1. Thus no such elementary primitive exists. The error function is introduced precisely to name this non-elementary integral.
